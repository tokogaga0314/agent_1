# DOCTYPE_html 問題與優化建議

## 結論先講
這份頁面 **可以運作**，但目前更像「可展示的靜態單頁原型」，還不到完全穩定、可維護、可長期擴充的版本。

---

## 一、檔案層級問題

### 1. `.md` 裡包著完整 HTML
**現象**：原始檔名是 Markdown，但內容主體其實是 HTML。

**影響**：
- 若直接當 Markdown 平台內容使用，可能不會正確渲染成完整頁面
- 若要給瀏覽器直接打開，最好另存為 `.html`

**建議**：
- 保留原稿作為參考
- 另建立正式可執行檔案，例如 `index.html`

### 2. 檔案開頭多了一行 `#`
**現象**：Markdown 第一行是 `#`

**影響**：
- 若原樣複製成 HTML，有機會在 `DOCTYPE` 前面混入多餘內容
- 雖然部分瀏覽器仍可容錯，但不乾淨

**建議**：
- 正式 HTML 版移除這一行

---

## 二、前端結構問題

### 3. `view-pane` 的 active class 沒有完整被 JS 維護
**現象**：
- CSS 依賴 `.view-pane.active`
- 但 `switchTab()` 實際上只改 `style.display`
- 沒有同步增減 `.active`

**影響**：
- 初次載入可正常顯示
- 後續切 tab 時，`fadeIn` 動畫與狀態語意不一致
- 之後若擴充樣式，容易出現 class 與畫面狀態不同步

**建議**：
- 切 tab 時同步維護 `.active`

### 4. `showDay()` 依賴 DOM 順序
**現象**：
- 使用 `querySelectorAll('.day-view')` 的索引對應日期

**影響**：
- 只要之後插入新節點、改順序、或某天被移動，對應就可能錯

**建議**：
- 直接用 `id="day1-content"` 這類明確 selector 切換

### 5. `hide-scrollbar` class 被使用但沒有定義
**現象**：
- `main` 上有 `hide-scrollbar`
- CSS 內沒有這個 class 的規則

**影響**：
- 命名存在，但功能未實作
- 可讀性與維護性下降

**建議**：
- 補上 scrollbar hidden 樣式

---

## 三、可用性 / UX 問題

### 6. 日期切換按鈕缺少語意與可及性屬性
**現象**：
- 沒有 `aria-selected`、`aria-controls` 之類屬性

**影響**：
- 螢幕閱讀器較難理解目前選到哪一天
- 無障礙支援不足

**建議**：
- 幫日期按鈕補上 aria 狀態

### 7. 互動狀態太依賴顏色
**現象**：
- active 幾乎只靠深色背景區分

**影響**：
- 對低視能或某些光線環境下辨識度不夠穩定

**建議**：
- 加粗字重、微位移或 outline 讓 active 狀態更明確

### 8. 內容是固定字串，資料與畫面沒有分離
**現象**：
- 所有行程資料直接硬寫在 HTML 裡

**影響**：
- 後續改日期、地址、時間要直接改 DOM
- 不利於重用或轉成可維護資料來源

**建議**：
- 若要進一步升級，可把資料抽成 JSON
- 再由 JS render timeline

---

## 四、內容細節問題

### 9. 行程安排曾出現跨日項目位置不一致
**現象**：
- 現有版本與上傳版本相比，`豪德寺` 曾出現在 Day 2 / Day 4 不同位置

**影響**：
- 表示資料版本可能混用
- 若直接發布，容易讓旅伴看到不同版本

**建議**：
- 正式版固定為單一版本
- 這次整理後以最新上傳版本為主

### 10. 文案容易混入符號 typo
**現象**：
- 例如 `五重塔＋富士山’` 這種引號符號不一致

**影響**：
- 視覺上會顯得像拷貝殘留或編碼問題

**建議**：
- 正式版統一標點與全半形

---

## 五、正式整理時建議保留的優點

這份檔案其實有幾個做得不錯的地方：

1. **手機優先很明確**
2. **視覺風格一致**
3. **卡片分色有助閱讀**
4. **時間軸呈現很適合旅遊手冊**
5. **互動量剛好，不會太重**

---

## 這次整理方向
本次正式整理版建議做以下事：

1. 移除 Markdown 殘留
2. 輸出乾淨可直接執行的 `index.html`
3. 修正豪德寺位置為最新版本
4. 修正常見 typo / 標點問題
5. 補上 `hide-scrollbar`
6. 讓 `switchTab()` / `showDay()` 的 active 狀態更一致
7. 補最低限度 aria 屬性
