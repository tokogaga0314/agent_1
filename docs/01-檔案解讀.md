# DOCTYPE_html 檔案解讀

## 檔案性質
這份內容本體是 **完整 HTML 頁面**，只是被包在 `.md` 檔案裡。真正能直接在瀏覽器渲染的是 `<!DOCTYPE html>` 到 `</html>` 之間的內容。

## 整體用途
它是一個 **手機版旅遊行程手冊頁面**，主題為：

- 東京富士山｜2026 家族旅行手冊
- 風格偏向精緻、雜誌感、家族旅行紀念冊
- 主要給手機瀏覽使用

## 技術結構

### 1. HTML 骨架
- `<!DOCTYPE html>`：宣告 HTML5
- `<html lang="zh-Hant">`：繁體中文頁面
- `<head>`：字型、樣式、外部資源
- `<body>`：實際 UI 內容

### 2. 外部資源
- `tailwindcss`：快速套用工具型樣式
- `font-awesome`：底部 icon
- `Google Fonts`：
  - `Noto Sans TC`
  - `Noto Serif TC`

### 3. 自訂 CSS
主要負責：
- 色彩系統（米白、灰黑、金棕、淡藍、淡綠）
- header / footer 固定結構
- 首頁 hero 區塊
- 航班卡片
- 日期切換列
- timeline 卡片與節點
- 住宿 / 美食 / 服務三種卡片視覺區分

## 頁面內容結構

### A. Header
用途：顯示品牌感與日期範圍。

包含：
- 左側：`Travel Memoirs`
- 右側：`2026.05.21 — 05.25`

### B. Main Scroll Container
`#mainScroll`

用途：
- 承接主要可捲動區域
- 讓 header / footer 固定時，中間內容仍可上下捲動

### C. 首頁分頁 `#view-home`
首頁是概覽頁，內容包含：

1. Hero 區塊
   - `Family Expedition`
   - 主標：`東京富士．精緻慢旅 與家人的記憶篇章`

2. 航班摘要卡
   - 去程：虎航 IT700
   - 回程：虎航 IT203
   - 顯示起降時間與行李額度

3. CTA 按鈕
   - `開啟詳細行程計畫`
   - 點擊後切到 schedule 分頁

### D. 行程分頁 `#view-schedule`
這是主要行程頁，分成兩塊：

#### 1. 日期切換列 `.sticky-nav`
- 5 天按鈕
- 使用者可切換 21 / 22 / 23 / 24 / 25
- 目前使用 `showDay(n)` 顯示對應日期內容

#### 2. Timeline 區塊 `#timeline-box`
- 左側垂直線：`timeline-v-line`
- 每個行程項目：`timeline-item`
- 每個節點：`timeline-node`
- 每張卡片：`event-card`

## 視覺語言

### 卡片類型
- `.stay-card`：住宿
- `.gourmet-card`：美食

### 文字層級

- `.time-capsule`：時間標籤

## 互動邏輯

### `switchTab(tabName)`
功能：
- 切換「概覽 / 行程」兩個主分頁
- 隱藏其他 view-pane
- 更新底部 tab 的 active 狀態
- 重設滾動位置到最上方

### `showDay(dayNum)`
功能：
- 切換某一天的內容
- 更新日期按鈕 active 狀態
- 只顯示對應 `day-view`
- 將捲動位置拉回頂部

## 結論
這份檔案本質上是：

它不是單純設計稿，而是可以直接打開使用的前端頁面雛形。
